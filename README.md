# 🏦 Sistema Bancário em Python

## Sobre o projeto

## O programa solicita:

- Nome do usuário
- Opção desejada no menu
- Valor para depósito, quando selecionado
- Valor para saque, quando selecionado

Com essas informações, o programa permite que o usuário interaja com uma conta bancária, consulte seu saldo, consulte seu histórico de transações e realize operações de depósito e saque.

## Funcionalidades:

- Consultar saldo da conta
- Realizar depósitos
- Realizar saques
- Exibir o histórico de transações
- Encerrar o programa

## Tecnologias:

🐍 Python 💻 Visual Studio Code

## Conceitos praticados

- Variáveis
- Entrada e saída de dados (input e print)
- Estruturas condicionais (if / elif / else)
- Estrutura de repetição (while)
- Operadores matemáticos
- Manipulação de valores numéricos
- Formatação de strings com f-strings
- Listas

Este projeto faz parte da minha jornada de estudos em programação, com foco no desenvolvimento da lógica de programação e no aprendizado de Python.
